# VulcanAcademy project instructions

- After every user-visible implementation, update `data/patch-notes-highlights.json` with a concise benefit-focused note before running the build.
- Keep patch-note copy in Portuguese, sentence case, and understandable without technical knowledge.
- Do not add secrets, personal data, internal endpoints, or security-sensitive implementation details to patch notes.
- `npm run build` regenerates `public/patch-notes.json` from recent Git commits automatically; do not edit that generated file by hand.
