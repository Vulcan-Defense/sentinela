Como ler os números

Os valores vêm da API pública do GitHub e representam o estado dos repositórios no momento da atualização. Eles mostram tração e colaboração — não qualidade ou segurança do código.

★ Estrelas
Interesse e visibilidade do repositório na comunidade.
⑂ Forks
Cópias usadas para estudar, adaptar ou contribuir.
◉ Colaboradores
Pessoas com commits contabilizadas pelo GitHub.
↻ Atividade
Data do último push registrado no repositório.

Dados: data/projetos.json · fonte: GitHub REST API. Nenhum projeto deste painel é afiliado ao PortWatch VI.
